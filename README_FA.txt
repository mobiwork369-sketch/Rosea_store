فروشگاه اینترنتی رُزآرا – نسخه اولیه قابل توسعه
===============================================

فناوری‌ها:
- Front-end: HTML5, CSS3, JavaScript
- Back-end: PHP 8+ با PDO
- Database: MySQL / MariaDB
- رابط راست‌چین و فارسی، واکنش‌گرا

راه‌اندازی با WampServer:
1) پوشه rosea_store را در مسیر www کپی کنید.
2) WampServer را اجرا کنید و Apache و MySQL را روشن کنید.
3) در مرورگر phpMyAdmin را باز کنید.
4) فایل database.sql را Import کنید.
5) در صورت نیاز مشخصات اتصال دیتابیس را در includes/bootstrap.php تغییر دهید.
   توجه: نام کاربری root و رمز دیتابیس فقط برای اتصال PHP به MySQL است؛ این اطلاعات، نام کاربری و رمز ورود مشتری یا مدیر سایت نیستند.
6) آدرس http://localhost/rosea_store/ را باز کنید.

ورود به پنل مدیریت (نسخه محلی):
- نشانی پنل: http://localhost/rosea_store/admin/
- ایمیل مدیر: admin@roseara.local
- رمز عبور اولیه: Rosea@2026!
- این حساب هنگام Import فایل database.sql ساخته می‌شود. برای امنیت، پس از ورود رمز را عوض کنید و این رمز نمونه را در سایت واقعی استفاده نکنید.
- حساب‌های ثبت‌نامی عادی به‌صورت پیش‌فرض نقش customer دارند و از فرم ثبت‌نام نمی‌توانند مدیر شوند.

بخش‌های پیاده‌سازی‌شده:
- صفحه اصلی، هدر، اسلایدر، دسته‌بندی‌ها، محصولات منتخب، بنرها، مجله، دیدگاه‌ها و فوتر بزرگ
- صفحه فهرست و جزئیات محصول، جستجو و فیلتر دسته‌بندی
- سبد خرید سمت مرورگر و ثبت سفارش در پایگاه داده
- ثبت‌نام، ورود، خروج و حساب کاربری
- ثبت دیدگاه فقط برای کاربر واردشده؛ نمایش دیدگاه‌های تأییدشده برای همه
- پنل مدیریت محصولات، سفارش‌ها، دیدگاه‌ها و مقالات
- صفحات تماس، راهنمای خرید و پرسش‌های متداول
- بدون خبرنامه و بدون دسته‌بندی لوازم آرایشی

نکات تکمیلی پیش از انتشار واقعی:
- درگاه پرداخت آنلاین هنوز متصل نشده و باید با اطلاعات پذیرنده واقعی پیاده‌سازی شود.
- ارسال پیامک، محاسبه هزینه ارسال، بازیابی رمز عبور و آپلود امن تصویر محصول در این نسخه نیست.
- برای محیط واقعی، HTTPS، تنظیم رمز قوی دیتابیس، محدودسازی تلاش ورود، اعتبارسنجی تکمیلی،
  سیاست حریم خصوصی و تست امنیتی ضروری است.
- مقادیر و تصاویر محصولات نمونه هستند و باید با اطلاعات واقعی فروشگاه جایگزین شوند.
- مسیرها و متن‌های نمونه تماس، نشانی و شبکه‌های اجتماعی باید با اطلاعات واقعی جایگزین شوند.


به‌روزرسانی طراحی اسلایدر و ساختار فرانت‌اند
---------------------------------------------
- اسلایدر صفحه اصلی اکنون سه اسلاید مستقل دارد: کمپین عمومی رُزآرا، بنر عطر و بنر مراقبت پوست.
- تصویر و متن هر اسلاید جدا هستند؛ متن‌ها HTML واقعی‌اند و روی تصویر قرار می‌گیرند، نه اینکه داخل عکس نوشته شده باشند.
- تصاویر اختصاصی و بدون نوشته در مسیر img قرار دارند: banner-slider-perfume.jpg و banner-slider-skincare.jpg.
- اسلایدر دارای دکمه قبلی/بعدی، نقطه‌های انتخاب، پخش خودکار، توقف/ادامه، توقف هنگام تعامل کاربر و پشتیبانی از prefers-reduced-motion است.
- کدهای استایل در assets/style.css و رفتارهای تعاملی در assets/app.js نگهداری می‌شوند.
- صفحات PHP نقش قالب سمت سرور را دارند تا اطلاعات دیتابیس به HTML تبدیل شود؛ این جداسازی در پروژه‌های PHP متداول است. منطق پایگاه داده و پردازش درخواست‌ها در فایل‌های PHP و includes نگهداری می‌شود.
- منوی مراقبت پوست زیرگروه‌های اصلی بیشتری را نمایش می‌دهد. برای نمایش محصول در هر زیرگروه باید محصولات متناظر با کد دسته‌بندی آن در پنل مدیریت/دیتابیس ثبت شوند.
- عنوان و توضیحات متای صفحه اصلی و Open Graph اضافه شده‌اند. برای سئوی کامل انتشار، باید دامنه واقعی، canonical، sitemap.xml، robots.txt، داده ساختاریافته محصولات و محتوای اصیل هر محصول تکمیل شود.
- صفحه فروشگاه اکنون دسته‌بندی کلی «مراقبت پوست» را به‌صورت گروهی نمایش می‌دهد و فیلترهای زیرگروه‌ها نیز در دسترس هستند.
- پنل مدیریت شامل فهرست مشتریان، تعداد سفارش‌ها و مجموع خرید آن‌هاست؛ مدیریت محصولات امکان افزودن، ویرایش و غیرفعال‌سازی محصول را دارد.


توضیح ساختار فایل‌ها
-------------------
- assets/style.css فایل مستقل استایل و assets/app.js فایل مستقل رفتارهای مرورگر است.
- فایل‌های PHP صفحه‌های سمت سرور هستند: PHP اطلاعات و نشست را مدیریت می‌کند و HTML خروجی صفحه را می‌سازد. پسوند PHP به معنی PHP-only بودن فایل نیست.
- تبدیل همه صفحه‌ها به HTML مستقل، مستلزم انتقال پردازش فرم‌ها و داده‌های پویا به APIهای PHP و اتصال آن‌ها با JavaScript است؛ صرفاً تغییر پسوند به .html باعث کارکرد فرم ورود، سبد خرید و پنل مدیریت نمی‌شود.

---------------------------------------------
به‌روزرسانی‌های اعمال‌شده (نسخه بهبودیافته)
---------------------------------------------
1. صفحه ثبت‌نام و ورود کاملاً بازطراحی شد:
   - ساختار HTML تمیز و خوانا
   - اعتبارسنجی بهتر (نام، ایمیل، موبایل ۰۹)
   - ظاهر شیک‌تر با کارت مرکزی و دکمه گرادیان

2. فوتر حرفه‌ای‌تر شد:
   - نوار نمادهای اعتماد (پرداخت امن، ضمانت اصالت، بازگشت ۷ روزه، ارسال سریع)
   - محل قرارگیری نماد اعتماد الکترونیکی (اینماد)

3. استایل‌های جدید در assets/style.css اضافه شد (بخش Auth و Trust Bar)

نکته مهم درباره جداسازی HTML و PHP:
در پروژه‌های PHP سنتی و فروشگاهی، ترکیب HTML و PHP در فایل‌های .php کاملاً استاندارد و حرفه‌ای است.
فایل‌های header.php و footer.php جدا شده‌اند و منطق دیتابیس در includes قرار دارد.
تبدیل کامل به HTML خالص + API نیاز به معماری SPA دارد که برای این پروژه ضروری نیست.
